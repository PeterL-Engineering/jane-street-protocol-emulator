## Jane Street Protocol Emulator

This repo contains my submission to the
[2027 Jane Street protocol emulator challenge](https://blog.janestreet.com/protocol-emulator-asic-competition/).
Included here is the main ASIC files written in SystemVerilog and
an assembler for the custom ISA.
